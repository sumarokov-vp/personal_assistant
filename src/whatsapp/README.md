# WhatsApp — источник переписки

Контекст объединяет реализации протокола источника переписки (`src/conversations/`) для WhatsApp.
Реализация привязана к платформе, где стоит клиент WhatsApp и лежит его локальная база, поэтому
каждая платформа — свой подпакет рядом, а бот и `file_take` видят только протокол:

- `macos_desktop/` — WhatsApp Desktop на macOS: чтение снимка его базы `ChatStorage.sqlite` и
  скачанных медиа, который делает хост-процесс (`macos_desktop/host/`)
- Linux-вариант для серверов, где стоят копии ассистента, появится отдельной реализацией того же
  протокола рядом с `macos_desktop/` — без правки инструментов бота и `file_take`

Вне платформенных подпакетов здесь нет ничего платформенного: общий код появляется, только когда у
двух реализаций он окажется фактически общим.
